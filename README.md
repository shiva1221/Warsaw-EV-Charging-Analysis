# ⚡ Warsaw EV Charging Network Analysis

An end-to-end Data Analytics project focused on analyzing EV charging infrastructure across Warsaw, Poland using SQL and Power BI.

This project explores charging station distribution, infrastructure gaps, energy usage patterns, customer behavior, and revenue optimization opportunities.

---

# 📊 Project Overview

The goal of this project was to analyze:

- EV charging infrastructure distribution
- Charging demand and peak usage
- Customer charging behavior
- Revenue performance by district
- Infrastructure readiness gaps
- Strategic expansion opportunities

The project combines:

- SQL analysis (14 business queries)
- Interactive Power BI dashboards
- Business insights presentation
- Strategic recommendations

# 🚨 Major Business Insights

- 5 districts have zero charging infrastructure despite projected EV growth
- Ursynów and Wesoła contribute ~36% of total revenue
- High-income districts remain under-served
- Mid-range districts provide the most stable ROI
- Warsaw currently faces a major EV infrastructure deficit

---

# 💡 Strategic Recommendations

- Expand charging infrastructure in zero-coverage districts
- Increase DC Fast Charger deployment
- Implement dynamic pricing during peak hours
- Develop loyalty programs for repeat users
- Reallocate investment from over-served districts
